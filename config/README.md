# parameters explanatin

## `baseline.tsv` parameters file
The `baseline.tsv` file contains the identical parameters used in the analysis stored in the official GitHub repository and presented within the paper.
It is used by the following ablations:
* baseline (no ablation)
* random identifiers of compounds
* only pathways computed, this is, families not computed

## `no_filter.tsv` parameters file
The `no_filters.tsv` contains parameters that disable the filtering of the m/z features.
It is used by only one ablation:
* no filter
